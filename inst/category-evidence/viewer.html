Complete evidence tables

Data, methods & interpretation

These TSVs cover the full selected analysis/collection/tier, not just the current display. The standardised DE table is stored once in genes.tsv; category connections reference exact gene symbols. ORA overlaps are not mixed into GSEA leading edges.

Leading-edge Jaccard = intersection / union of unique leading-edge genes. Overlap tables report both set sizes, intersection, union and NES direction. The default displayed_leading_edge_overlaps.tsv covers only the default displayed significant sets, not all mapped sets. Select a set above to compare it with every mapped set and download those rows. An optional all_leading_edge_overlaps.tsv is produced only when full all-pair export is explicitly requested. It is NA when either membership is empty or unrecorded, not evidence of dissimilarity. Complete-set overlap, if supplied, follows the same explicit pair scope in a separate export and must not be interpreted as leading-edge overlap. Overlap is descriptive redundancy, not causal evidence.

“Non-evaluable” means valid NES and adjusted P value were unavailable or the set was ineligible. “No significant sets” and absent leading-edge genes are explicit states, not evidence that a category is inactive. The assigned category is semantic metadata; inspect the original sets and gene-level measurements.
